本课程面向航空专业本科生与低年级研究生，从工程实际出发，逐步介绍统计学习方法在飞行器专业中的应用。

正文按章、节组织：先学习数学工具与统计学习方法，再进入飞行器建模、导航、控制、制导与综合实验。程序设计、框架用法与工程文档放在附录，供需要时查阅。
