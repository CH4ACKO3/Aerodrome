本手册面向航空专业本科生与低年级研究生，从工程实际出发，逐步介绍统计学习方法在飞行器专业中的应用。

正文按章、节组织：先学习数学工具与统计学习方法，通过独立的强化学习章节连接动态规划与最优控制，再进入飞行器建模、导航、控制、制导与综合实验。程序设计、框架用法与工程文档放在附录，供需要时查阅。

数学工具基础包含六节正文；统计学习方法包含五节，覆盖学习简介、线性模型、深度神经网络、其它方法与强化学习简介，配有示意图、手算例和可运行短程序。各章从直觉和工程用途出发，必要推导供后续查阅；第三章“强化学习”用七节连接最优反馈、参数化、在线规划、价值学习与策略优化，并讨论共同控制任务上的比较。第四章“飞行器建模与数值仿真”用九节连接坐标与姿态、刚体动力学、数值积分、环境与部件、固定翼与旋翼建模，以及配平、线性化和仿真验证；后续章节将逐步编写。
