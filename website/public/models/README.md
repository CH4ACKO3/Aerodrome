# Teaching assets

`training-fighter.glb` and `training-city.glb` are original procedural teaching
geometry generated by `website/scripts/generate-scene-assets.mjs`, dedicated to
the public domain under CC0-1.0. They are not surveyed terrain, an actual city,
or an accurate F-16 model. The fighter has named elevator, rudder and aileron
nodes for articulation tests. Geometry is in metres, nose -Z, right +X, up +Y.
`manifest.json` declares the required asset-to-FRD quaternion.

Replace the GLB through the renderer's asset map; preserve the correct units,
asset orientation, node pivot/rest pose and licensing metadata. Importing a
fighter's appearance does not provide its aerodynamic or propulsion model.
