# 工程 03：可变规模集合上的局部协同

本工程先把**数量变化、成员事件、局部观测和共享策略**做成可复现实验。对象是二维双积分点质量，不是四旋翼或固定翼。当前任务是沿匀速参考保持一个有间隔的队形，尚未实现障碍穿越、区域覆盖或失联恢复。

零号工程入口：[运动积分](../../docs/project-zero.md#dynamics) · [控制](../../docs/project-zero.md#control) · [环境事件](../../docs/project-zero.md#environment) · [学习](../../docs/project-zero.md#learning) · [评测](../../docs/project-zero.md#evaluation) · [代码写法](../../docs/project-zero.md#coding-styles)。

## 运行与阅读

在 `ngc/` 目录完成项目依赖安装后执行：

```sh
uv run --locked --all-extras python projects/variable_team/run.py --output artifacts/variable-team
```

脚本自动完成示范采集、线性拟合、18 次留出评测、排列重排验证和单因素调优；不需下载模型、不需 GPU。先读 `summary.md`，再按下表加载同一次运行的数字。`metrics.json` 的墙钟时间由本机实际测量。

依赖零号工程组件主题：时间步/输入保持、点质量动力学、PD反馈、环境与成员事件、数据拟合、批量评测、代码编写方式。本文件用普通函数拆开这些环节，入口只是组装；无需先理解继承和插件系统。

## 数学对象与可用信息

- 状态：每个有效成员的位置 `p_i∈R²`（m）和速度 `v_i∈R²`（m/s）。
- 输入：加速度 `a_i∈[-3,3]²`（m/s²），每 `0.05 s` 保持一次，仿真 `18 s`。
- 动力学：共享 `aerodrome.models.point_mass.step` 用精确零阶保持积分双积分器。
- 参考：`r(t)=(0.35t,0)`，参考速度 `(0.35,0)`；角色偏置 `d_i=(0,2.5(i−4))` 随稳定成员 ID 固定。
- 观测：自身 `e_i=p_i−d_i−r`、`w_i=v_i−r_dot`，以及距离小于 `4.5 m` 的有效邻居的这些误差。所有方法知道共同参考、自己的角色和自身状态；它们不知道有效总人数。
- 通信：同步、无噪声、无延迟，范围图随位置变化。角色分配已给定，策略没有解决角色分配问题。

固定容量为 9，有效 mask 表示哪些槽位参与任务。训练分别使用 2/4/6 个成员，评测初始人数为 3/5/8；第 6 秒 ID=1 退出，第 10 秒新的 ID=count 加入，因此有效人数先减一再加一。加入节点在自己的参考位置附近初始化。退出后该槽位静止，并从邻居、控制与指标排除。

**容量不是可见人数。** 当前实现的上限就是 9；没有声称支持任意规模。新成员加入时，已有成员保持原角色，并不重新压缩队形。

## 三种方法

`observations` 构造每轴 4 个特征：自身误差、自身速度误差、与邻居均值的误差差、与邻居均值的速度误差差。没有邻居时后两项为零。邻居均值与输入数组顺序无关。

1. `independent`：`a=-1.4e-2.1w`，把广播参考看作虚拟领机，各成员独立跟踪。
2. `consensus`：在上式增加 `-0.55(e-mean_neighbor_e)-0.45(w-mean_neighbor_w)`。这是带自身参考锚定的局部一致性，不是仅依靠邻居就能知道全局轨迹。
3. `learned`：用前述 4 维观测拟合共享线性系数。示范来自 `consensus` 的实际限幅后动作，最小二乘 `lstsq(X,y)` 真正读取采集数据；所有人数、所有成员、两个轴共享同一组权重。执行阶段再次使用共同限幅。

数据方法恰好包含教师的线性形式，所以接近教师是有解释的结果，并不是“学会了更优控制”。没有强化学习，没有神经网络。若大量示范进入饱和，单个线性模型不再能精确拟合教师；这也是可做的小实验。

## 数据划分与评价

训练 seed 为 11/12/13，训练时无成员事件。留出 seed 为 101/102，人数和成员事件均不同。每个方法使用完全相同的初始条件和事件；重排验证另外将存储槽位置换后按成员 ID 对齐整段位置轨迹。

完成要求：最后 3 秒有效成员的队形跟踪 RMSE 小于 `0.12 m`，且整个实验最小机间距不小于 `0.3 m`。报告还包括全程 RMSE、加入后的持续恢复时间、控制平方和及邻居数量。误差按有效成员/有效时刻平均，人数增加不会直接使分数增加。

`minimum_separation_m` 是**全部真实物理区间的连续最小间距保守下界**。先求每对成员相对运动端点弦的最小距离，再扣除 `||a_i−a_j|| dt²/8`，最后截到非负。该扣除量是精确零阶保持抛物线与端点弦的最大偏差，因此不会把弯曲轨迹的最小间距高估为弦的距离。`collision=true` 表示下界触及 0.3 m 阈值、存在潜在碰撞，不能反过来声称已经证实碰撞；`collision=false` 则在本点质量/ZOH模型内证明该距离阈值未被触及。

每个区间使用当步 `active` 和真正积分出的 `end_position`：5.95→6.00秒仍完整计入即将退出成员，6.00秒才将其移除；新成员在10秒初始化，没有把其旧无效槽位位置连成一段虚假运动。最后17.95→18.00秒同样参与连续间距评价。

运行会额外保存邻居耦合倍率 `0/0.5/1/1.5` 的同工况调优表，固定参考、seed、PD增益及输入上限。观察增大耦合对误差和输入代价的影响，而不是只公布一个最好数字。该调优工况是 4 成员、seed=31，独立于最终测试集。

回放应只绘制 `active=true` 的成员，以 `member_ids` 关联事件。轨迹的 `time/position/velocity` 每一行是**当前状态与本步将执行的动作**，时刻从0到17.95秒，没有额外的 `time=18` 状态行。`end_time/end_position` 另存每步积分后的时间和位置，最后一行包含18秒位置终态（未额外保存18秒速度）；可以据此播放完整18秒的位置轨迹。`separation_lower_bound` 对应每个 `[time,end_time]` 物理区间。图中的通信边直接来自同一帧 `neighbors`，不在浏览器重新实现控制算法。

## 建议学习顺序与局限

先将耦合设为零理解独立反馈，再恢复邻居项，最后查看学习得到的权重。随后尝试缩小通信范围、增大初始偏差、让更多输入饱和。保留所有失败，不把训练误差低当作闭环成功。

当前存在广播参考和给定角色，因此不是完全无领导的自治协作。没有传感器噪声、通信故障、拥挤避碰或任务分配，最小间距良好主要依赖宽松初态和队形间隔。把它接到真实旋翼机前，需要补姿态/推力内环及可执行性验证，不能直接把加速度数组当作电机指令。
