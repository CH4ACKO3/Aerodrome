# 数学工具基础：内容编排

本次面向低年级工科本科生。默认读者会初等代数、函数图像和一元求导；矩阵、概率、优化算法都需在使用处建立直觉。任务不是压缩一本数学教材，而是使读者理解后续建模、估计、学习和控制真正会用到的对象，能预测一个简单例子并检查计算结果。

## 主线与写法

沿“描述状态—表达不确定性—从数据估计—选择行动—求解当前问题—考虑未来后果”推进。共同背景是一维运动对象的位置和速度、带噪读数以及有限资源；不要求读者预先懂航空术语。每节选择一个能手算的主例，先问具体问题，再介绍符号和条件。通过数量、形状、单位、图像和反例纠正容易形成的错误直觉。

正文以连贯段落解释，公式不跳过关键代入。每节有少量带答案或提示的练习、前后节链接和零号工程入口。不要把学习材料写成名词清单、API 清单或论文方法优越性论证。数值是构造例时明确说是设定，不伪装成实际测量。读者暂时不运行代码也应理解主线。

## 逐节设计

| 节 | 直觉问题 | 核心内容与主例 | 本轮边界 |
|---|---|---|---|
| 1.1 线性代数 | 如何把位置和速度一起算？某个观测丢掉了哪些信息？ | 用二维箭头、线性组合、一步状态更新解释矩阵；范数须注意不同单位；用重复观测解释秩，用残差解释最小二乘；梯度是局部变化率 | 保留已有完整正文与 JAX 下载示例；增加初读路径；矩阵微分与高阶规则作为可回查进阶内容，不强迫初读掌握 |
| 1.2 概率论 | 同一位置为什么会得到不同读数？报警后应相信到什么程度？ | 随机变量、分布、期望和方差、联合/条件概率、贝叶斯更新、相关与独立、连续密度；用低发生率检测的自然频数表推导后验 | 不讲测度论与分布大全；高斯模型是近似；密度不是单点概率，期望不一定能实际取到 |
| 1.3 统计 | 手里只有一组读数，能知道模型多少？ | 总体与样本、样本均值和波动、偏差与标准误、独立样本平均降噪的条件、简单回归与残差、训练/验证/测试的区别 | 不堆假设检验公式；不把标准差和均值不确定性混为一谈；同条轨迹随机拆帧可能泄漏，系统偏差不会因重复平均消失 |
| 1.4 决策论 | 最可能的情况是否总该决定行动？ | 状态与行动分开，损失表，条件期望损失，阈值，风险偏好与信息价值；用检查/继续运行的设定损失示例 | 不引入博弈均衡证明；损失是目标设定，不是自然定律；期望最优不保证单次最好 |
| 1.5 优化 | 怎样在允许的动作里找到更合适的一个？ | 变量、目标、约束、可行域；二次曲线的梯度步与步长；边界解不必梯度零；局部与全局；小型离散分配反例 | 不展开 KKT/对偶证明；区分算得对与目标设得对；连续梯度法不能直接取代离散分配 |
| 1.6 动态规划 | 当前省下的代价会不会留到未来？ | 状态要足够描述未来，转移、阶段代价、终端代价、策略；有限时域倒推一个三状态两步问题，得到 Bellman 递推；随机后继用条件期望 | 不讲连续 HJB/PDE 与强化学习训练细节；区分值函数、策略、轨迹；说明维数增长、有限网格、已知模型等条件 |

## 可核对的贯穿数值

1. 概率例：假设 10000 个样本中 1% 状态异常；异常时报警率 90%，正常时误报率 5%。报警样本约为 90+495，报警后的异常概率为 90/585，约 15.4%。这些比例是教学设定，不是器件实测性能。
2. 统计例：读数 9.8、10.0、10.2、10.0、10.0，样本均值 10，分母 n−1 的样本方差 0.02，标准差约 0.1414，独立同分布假设下估计的均值标准误约 0.0632。不要由这五个值直接声称得到了严格的 95% 区间。
3. 决策例：继续时正常损失 0、异常损失 100；检查时两种状态损失均为 2。q 是当前异常概率，继续的期望损失为 100q，检查为 2；q>0.02 时选检查，相等时两种行动并列。成本单位是统一的设定代价。
4. 优化例：无量纲 u 的目标 J(u)=0.5(u−2)^2，从 0 以步长 0.5 更新得 1、1.5、1.75；若限制 −1≤u≤1，最优解在 1，目标梯度为 −1。离散分配代价 [[1,2],[2,100]]，逐个贪心可能得到 101，而交叉分配总成本为 4。
5. 动态规划例：状态 s∈{0,1,2}，动作是停留 a=0 或前进 a=1（不能越过2），转移 s'=s+a，阶段代价 a²，两步后终端代价 4(2−s)²。V2=[16,4,0]，V1=[5,1,0]，V0=[2,1,0]。在初始状态0的一条最优轨迹是0→1→2。某些状态存在并列最优动作，应明确保留。

作者可以调整例子来改善说明，但必须同步重新核对数值，不能混用不同设定。

## 对照教材后的项目范围修订

PML 用来核对概念和教学质量，不作为逐项补齐的目录。读者仍为低年级工科本科生，取舍以本项目的建模、估计、学习、控制和实验比较为依据。不增设信息论，不展开分布大全、一般图模型、完整统计检验、KKT 证明或无限时域强化学习。

| 节 | 本轮实际补全与调整 |
|---|---|
| 1.1 | 保留详细推导与已有编号，进阶内容折叠；补最小二乘投影、特征方向与误差椭圆、标准化和白化直觉 |
| 1.2 | 沿频数表补联合/边缘/条件关系与条件独立；一维独立测量融合、二维协方差与线性传播、有限抽样 |
| 1.3 | 沿原直线拟合例补高斯似然到平方误差；只惩罚速度的正则化；重复实验区分均值估计与未来读数误差 |
| 1.4 | 由处理时间例解释均值与中位数对应不同损失；小成本表对照预测 RMSE 与任务后果 |
| 1.5 | 二维曲率/尺度、批量梯度与小批量波动、耦合约束的投影；保留一维手算和离散分配 |
| 1.6 | 有限时域内先评价给定策略，再比较改进；标准库短程序与手算表一致，明确模型与状态已知 |

测量、拟合和决策共用 `ngc/examples/math_tools.py`；动态规划使用 `ngc/examples/finite_horizon_dp.py`。零号工程固定入口为 `#math-tools`，详细运行说明维护在 `ngc/docs/math-tools.md`。配图脚本复用重复拟合函数，避免图和程序维护两套算法。图例声明解析模型或有限次合成实验，不能当成实测结果。

每节以能解释问题、手算小例、预测参数变化方向、说明不适用条件为完成标准，不以篇幅或覆盖教材的比例验收。验证范围为新增算例及网站构建、公式和链接，不因文档扩写重复运行整个框架回归。
