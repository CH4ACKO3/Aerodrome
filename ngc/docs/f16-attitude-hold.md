# 最简单的 F-16 姿态控制例子

`control/f16_attitude.py` 使用固定增益反馈，`examples/f16_attitude_hold.py` 将它接到六自由度 F-16 的 World 输入。无需求解控制优化问题，也没有积分器状态。配平仍由已有六轴配平器提供。

在 `ngc/` 执行：

```sh
uv run --locked --extra control python examples/f16_attitude_hold.py
```

`--extra control` 提供绘图依赖，控制律本身只用 JAX。结果写入 `artifacts/f16_attitude_hold/`：对比图 `control.png`、全部轨迹与舵量 `trajectory.npz`、结果摘要 `summary.json`。可用 `--output` 指定其他目录。

## 四条控制律

所有角度为弧度，角速度为 rad/s；下标 0 表示平飞配平值：

```text
升降舵 = 升降舵₀ + 0.8 × (俯仰角 − 俯仰角₀) + 0.4 × q
副翼   = 副翼₀   + 0.4 × (滚转角 − 滚转角₀) + 0.15 × p
方向舵 = 方向舵₀ + 0.2 × r
推力 N = 推力₀   + 1000 × (空速₀ − 空速)
```

P 项把姿态拉回参考值，D 项用实测角速度抑制摆动；方向舵只做偏航阻尼，推力只做空速比例控制。这里采用“实际值减参考值”，因为本机体正升降舵产生负俯仰力矩，正副翼产生负滚转力矩。`Gains` 中可以直接调整这些增益。

输出舵量限制为升降舵 ±25°、副翼 ±21.5°、方向舵 ±30°；推力限制为 0..84500 N，与当前配平例子的范围一致，不代表真实发动机推力曲线。LEF 固定为配平值。反馈每 0.02 s 更新一次，控制量在两次 0.01 s 物理积分之间保持不变。近水平飞行时用 p、q 近似滚转和俯仰角的导数。

## 实验

150 m/s、3000 m 初始配平，同时施加滚转 +5°、俯仰 +2° 和 p/q/r = +1/+0.5/+1 deg/s 的初始扰动。比较三条轨迹：正扰动加反馈、全部取反的负扰动加反馈、正扰动但保持配平舵量和推力不变。

20 秒 CPU / float64 仿真结果：

| 工况 | 最终滚转误差 | 最终俯仰误差 | 最终空速误差 | 持续进入误差带 |
|---|---:|---:|---:|---:|
| 正扰动 + PD | +0.00048° | −0.00046° | −0.0195 m/s | 8.44 s |
| 负扰动 + PD | −0.00040° | +0.00038° | +0.0053 m/s | 3.44 s |
| 正扰动 + 固定配平输入 | +5.383° | +0.591° | −4.930 m/s | 未进入 |

误差带要求滚转/俯仰误差 <0.1°、三轴角速度 <0.1 deg/s、空速误差 <0.1 m/s，且之后直到实验结束都满足。端到端测试运行真实示例，并检查正负扰动恢复、对比轨迹、实际输出范围及产物保存。

这是局部姿态稳定例子，没有高度和航向保持。两条反馈轨迹仍分别积累约 +10.07 m 和 −10.16 m 的高度变化，不会回到原高度。使用无噪声真值反馈、直接舵偏和推力，没有传感器、舵机或发动机动态；当前增益只在上述小扰动工况验证。

NPZ 中状态的时间轴 `time_s` 包含初态和末态；`control_time_s` 对应区间起点，`controls` 在该时刻之后的 0.02 s 内保持。控制数组最后一维依次为升降舵、副翼、方向舵、LEF、推力，前四项为弧度，最后一项为 N。
